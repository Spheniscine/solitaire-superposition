# Superposition Solitaire

A web-and-mobile-friendly implementation of Superposition Solitaire (adapted from Tear Solitaire by Hempuli).

Note that drag-and-drop is not supported or needed. Moves are done by selecting the card or stack, then clicking its destination.

Play here: (ad-supported) [https://www.onlinemathlearning.com/solitaire-superposition-game.html]

Or here: [https://spheniscine.github.io/solitaire-superposition/]
